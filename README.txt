Teaching Journal Pro V5.2 — Absences & Holidays Workspace

Deployment:
1. Export a JSON backup from your current journal first.
2. Extract this ZIP.
3. Upload the files in this folder to the ROOT of your GitHub Pages repository, replacing the matching files.
4. Commit the changes and wait for GitHub Pages to deploy.
5. Refresh the app. If an older version remains cached, close the app and reload the GitHub Pages site.

Data compatibility:
- Existing sessions and timetable slots are preserved.
- Absences and holidays are stored additively in the existing teachingJournalPro_v1 backup structure.
- Existing V5 JSON backups remain restorable.
- Never delete timetable slots when adding an absence or holiday.

Workspace includes: absence/holiday forms, class targeting, partial-day time ranges, date range validation, calendar, affected timetable slot detection, status/rescheduling details, history search/filter/edit/delete, and report-preview additions.
